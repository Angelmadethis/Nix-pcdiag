PCDiag RULES

PCDiag is a diagnostic tool, not a placebo optimizer.

Never:
- change settings during scans
- recommend registry tweaks without strong evidence
- disable Windows security
- disable services for FPS
- claim a configuration is bad merely because it is non-default
- invent measurements
- infer root cause without evidence
- use arbitrary optimization myths
- hide failed checks

Always:
- collect evidence
- explain findings
- expose uncertainty
- provide confidence
- distinguish unavailable from healthy
- distinguish unusual from harmful
- prefer documented Windows behavior
- make diagnostics modular
- test calculations independently
- fail safely
